# FastAPI Backend Development Template

A complete, production-ready backend template built with modern Python frameworks.

## 🛠️ Tech Stack
- **FastAPI** — Web routing and Swagger documentation.
- **Pydantic V2** — Input/output payload validation.
- **SQLAlchemy 2.0** — SQL database representation.
- **Alembic** — Schema migrations.
- **MySQL** — Persistent storage.
- **Redis & Celery** — Asynchronous task queues and caching.
- **JWT Authentication** — JSON Web Tokens with Passlib password hashing.
