# 🐍 Complete Python Programming Course
## From Zero to Python Backend Developer

Welcome! This course is designed specifically for **beginners** who want to become **Python Backend Developers**.

---

## 📚 Course Structure

| # | Module | Topics |
|---|--------|---------|
| 01 | **Python Basics** | Variables, Data Types, Input/Output |
| 02 | **Operators & Expressions** | Arithmetic, Comparison, Logical |
| 03 | **Control Flow** | if/elif/else, Loops |
| 04 | **Functions** | def, Arguments, Return, Lambda |
| 05 | **Data Structures** | Lists, Tuples, Sets, Dictionaries |
| 06 | **Strings** | String Methods, Formatting, Slicing |
| 07 | **File Handling** | Read, Write, Append Files |
| 08 | **Error Handling** | try/except, Custom Exceptions |
| 09 | **Object-Oriented Programming** | Classes, Inheritance, Polymorphism |
| 10 | **Modules & Packages** | import, pip, Virtual Environments |
| 11 | **Comprehensions & Iterators** | List/Dict Comprehensions, Generators |
| 12 | **Decorators & Closures** | Higher-order Functions, @decorator |
| 13 | **Working with JSON & APIs** | json module, requests library |
| 14 | **Database Basics** | SQLite, SQL Queries with Python |
| 15 | **Introduction to FastAPI** | Your First Backend API |

---

## 🚀 How to Use This Course

1. Start from **Lesson 01** and go in order
2. Read the lesson file
3. Run the example code
4. Complete the exercises at the bottom of each file
5. Check `_solutions/` for answers

---

## ⚡ Prerequisites

- Python 3.10+ installed
- VS Code (recommended)
- Terminal / Command Prompt

---

By the end of this course, you will be able to:
- Write clean, professional Python code

- Build REST APIs with FastAPI
- Work with databases
- Deploy a real backend application
